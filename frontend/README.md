## 📌 What I Built

I built a responsive React-based dashboard that displays real-time cryptocurrency market data using the CoinGecko API. Users can select a crypto asset from a dropdown and view its current price, market cap, 24-hour volume, price change, and a 7-day price trend visualized in a line chart.

## 🛠️ Technologies Used

- **React** – for frontend logic and component structure
- **Tailwind CSS** – for styling and responsive layout
- **Axios** – for HTTP requests
- **Chart.js + react-chartjs-2** – for rendering price trend charts
- **CoinGecko API** – to retrieve live crypto data

## 🎨 UI Decisions

- Used **dark mode design** with Tailwind for a modern, clean look.
- Layout is mobile-responsive, optimized with `flex`, `grid`, and utility classes.
- Created modular components for Dropdown, Info Card, Chart, and List.
- Integrated a **line chart** to visually communicate price fluctuations.
